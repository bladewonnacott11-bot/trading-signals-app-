# SignalDesk

A modern, dark-themed trading signals web app for **options and equities**, offering two strategy modes: **Swing Trading** and **Scalping**.

> ⚠️ Base UI only — signal data is currently hardcoded. No live market data yet.

<!-- ============================================================
     2. OVERVIEW
     ============================================================ -->
## Overview

SignalDesk is a lightweight frontend built to display trading signals in a clean, simple interface. The goal is to build the full UI first, then wire in real market data and broker connections later.

<!-- ============================================================
     3. FEATURES
     ============================================================ -->
## Features

- Dark modern theme with gradient accents
- Two switchable strategies: **Swing Trading** and **Scalping**
- Signal cards showing:
  - Symbol (e.g. `AAPL 190C`)
  - Direction (long / short)
  - Entry, Target, and Stop prices
  - Risk-to-Reward ratio
  - Confidence score bar
  - Status (active / pending / closed)
- Responsive layout (mobile + desktop)
- Clean, minimal UI focused on readability
